# ControlPay — Frontend Demonstrativo

Versão pública e estática do **ControlPay**, preparada para demonstração e portfólio.

> **Importante:** esta versão não possui backend, banco de dados, LDAP, APIs internas ou conexão com sistemas externos. Todos os dados exibidos são fictícios.

## ✨ Recursos

- Dashboard com indicadores
- Consulta de homologações
- Filtros demonstrativos
- Cadastro local de registros
- Relatório visual
- Exportação CSV
- Tema claro/escuro
- Layout responsivo
- Navegação sem backend
- Compatível com GitHub Pages

## 🧹 O que foi removido

A versão pública não contém:

- `.env`
- credenciais ou secrets
- LDAP
- banco de dados
- scripts SQL
- backend PHP
- endpoints REST
- configurações internas
- dados reais
- logos e imagens institucionais específicas
- dependências do servidor original

## 🚀 GitHub Pages

O projeto é composto somente por HTML, CSS, JavaScript e assets estáticos. Basta publicar a raiz do projeto pelo GitHub Pages.

Para desenvolvimento local, abra `index.html` ou utilize qualquer servidor estático.

## 📌 Observação

Este repositório é uma reconstrução **frontend/demonstrativa** baseada na interface do projeto original. Ele não representa uma cópia operacional do sistema interno.

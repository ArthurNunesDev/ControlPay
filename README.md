# ControlPay

Versão pública e demonstrativa do **ControlPay**, agora com a interface principal renderizada em **PHP**.

> **Importante:** esta versão pública não possui conexão com banco de dados, LDAP, APIs internas ou sistemas corporativos. Os dados apresentados são fictícios.

## ✨ Recursos

- Dashboard com indicadores
- Consulta de homologações
- Filtros demonstrativos
- Cadastro de registros
- Relatórios visuais
- Exportação CSV
- Tema claro/escuro
- Layout responsivo
- Renderização PHP
- JavaScript para interações da interface

## 🛠️ Tecnologias

- PHP
- HTML5
- CSS3
- JavaScript

## 🚀 Executar localmente

É necessário ter o PHP instalado.

```bash
php -S localhost:8000
```

Depois acesse:

`http://localhost:8000`

## 📌 Sobre a versão pública

O projeto original possuía componentes internos e integrações que não podem ser disponibilizados publicamente. Por isso, esta versão mantém a interface e a estrutura de apresentação em PHP, utilizando dados fictícios e sem acesso a sistemas internos.

Ela serve como demonstração técnica e portfólio, não como uma cópia operacional do sistema corporativo.
